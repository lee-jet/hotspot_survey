Claude-to-IM Skill · 把 Claude Code 接入 IM

将 Claude Code / Codex 通过后台守护进程桥接到 Telegram、Discord、飞书、QQ、微信，在聊天中直接驱动编码 Agent 并审批工具调用。

1. 结论摘要

推荐基线

已用 Claude Code 或 Codex CLI，希望离开终端、用手机 IM 远程发指令并审批 Agent 的工具调用时，最划算。

补充场景 / 替代

若想要图形化界面与会话管理，作者推荐改用 CodePilot 桌面版；纯本地使用或不需要远程触达时不必引入。

3. 应用场景

移动端远程编码

出门在外用 Telegram 让 Claude Code 改代码、跑命令

团队飞书协作

在飞书群里调用 Agent，审批文件编辑等高危操作

Codex 桥接

通过 CTI_RUNTIME=codex 复用同一桥接到 OpenAI Codex

4. 风险与缓解

凭证集中存储风险

五平台 token 集中在 ~/.claude-to-im/config.env，主机被攻破等于全部 IM Bot 失陷；务必保留 chmod 600 并隔离主机。

远程工具调用授权

IM 按钮一点即可让 Agent 写文件/跑命令，误点或账号被盗会造成代码破坏；配置 allowed_users 白名单并保留人工审批。

平台能力不一致

QQ 仅 C2C、无按钮无流式；微信单账号、无流式、语音仅取自带 STT 文本，跨端体验差异需提前预期。
